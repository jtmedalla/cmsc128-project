# Brand

How MIGO names and presents itself. Exact color values live in the web app's theme, [`apps/web/src/index.css`](../../apps/web/src/index.css).

## Name

**Project MIGO**: Miagao Incident Gateway for Operations.

"MIGO" plays on "amigo" (friend). It's approachable and easy to recall for residents reporting emergencies. The backronym signals its institutional job as MDRRMO's central intake system.

## Taglines

- "Kaibigan sa Oras ng Sakuna"
- "One Chat Away From Help."

## Logo

A firefighter helmet ([`apps/web/public/logo.svg`](../../apps/web/public/logo.svg)), based on [SVG Repo's firefighter helmets](https://www.svgrepo.com/vectors/firefighter-helmet/).

## Colors

| Role     | Token                                               | Use                                                       |
| -------- | --------------------------------------------------- | --------------------------------------------------------- |
| Navy     | `--primary`                                         | Main brand color, drawn from MDRRMO's uniform             |
| Orange   | `--highlight`                                       | Accent only: the logo, focus rings, a few calls to action |
| Semantic | `--success`, `--warning`, `--destructive`, `--info` | Status and feedback                                       |

## Typography

[Public Sans](https://fonts.google.com/specimen/Public+Sans), a highly legible sans-serif.
